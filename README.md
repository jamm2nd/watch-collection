# Watch Collection — jamm’s EDITION 1.0

개인 계정에 독립 설치하는 시계 컬렉션 웹앱입니다.

[설치 페이지](https://watch-collection-v1.jamm2nd.chatgpt.site/) · [설치 안내](INSTALL.md)

Sites 생성·배포 기능과 파일 작업 환경이 있는 GPT에서 INSTALL.md의 안내를 실행합니다. 받는 사람은 ZIP 다운로드나 파일 첨부를 할 필요가 없습니다. GPT가 이 공개 저장소의 파일을 직접 가져와 검증·복원합니다.

이 저장소의 JSON은 앱 코드·브랜드 로고·폰트·기본 샘플 시계 5개를 담은 비압축 설치 패키지입니다. manifest.json에 모든 파일의 SHA-256이 있으며 restore.py는 새 빈 폴더에만 복원합니다. 사용자 컬렉션, 개인 업로드, 계정 정보, 비공개 Site 식별자와 인증정보는 포함하지 않습니다.

복원 후 새 Site와 독립 DB·사진 저장소를 생성합니다. 운영 중 이 배포 저장소에 개인 기록을 저장하지 않습니다.

본 Watch Collection앱은 개량하거나 용도를 바꾸어 사용하는 것이 자유입니다. 브랜드 상표, 제품 사진 및 제3자 폰트의 권리는 각 권리자에게 있습니다.
