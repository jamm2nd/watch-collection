# Watch Collection — Ver. 1.03

설치 및 기존 컬렉션 업데이트: https://watch-collection-v1.jamm2nd.chatgpt.site/?v=1.03

ChatGPT 웹의 Work에서 @Sites로 시작합니다. Sites 제작·배포 기능과 소스 다운로드가 필요합니다. [설치 안내](INSTALL.md)

소스는 manifest.json에 명시된 부분 파일을 순서대로 검증·결합한 JSON 패키지입니다. restore.py를 검토한 뒤 새 폴더에 복원합니다. 기존 컬렉션 업데이트 시 데이터와 저장소를 유지합니다.

Ver 1.03: 사진 등록 버튼 위에서 앞면·뒷면을 선택하며, 선택 버튼 전체를 베이지색으로 표시합니다. 앞면만 썸네일 구도를 편집하고 뒷면은 원본 확인·확대와 업로드만 제공합니다. 사진 편집 버튼을 정렬하고 확대 보기에서는 저장된 원본 전체를 메뉴 없이 화면에 맞추고 좌우 스와이프 방향으로 빠르게 넘깁니다. 화면 클릭 또는 Esc로 닫습니다. 썸네일의 위치·크기 설정과 기존 데이터는 유지합니다.

Ver 1.02부터 앞면·뒷면 전환과 각 면 사진 등록 및 위치·크기 개별 조절을 지원합니다. 1.01 이하에서 업데이트 시 INSTALL.md의 저장 모델 병합 안내를 따릅니다.
