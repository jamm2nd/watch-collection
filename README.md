# Watch Collection — Ver. 1.04

설치 및 기존 컬렉션 업데이트: https://watch-collection-v1.jamm2nd.chatgpt.site/?v=1.04

ChatGPT 웹의 Work에서 @Sites로 시작합니다. Sites 제작·배포 기능과 소스 다운로드가 필요합니다. [설치 안내](INSTALL.md)

소스는 manifest.json에 명시된 부분 파일을 순서대로 검증·결합한 JSON 패키지입니다. restore.py를 검토한 뒤 새 폴더에 복원합니다. 기존 컬렉션 업데이트 시 데이터와 저장소를 유지합니다.

Ver 1.04: 앞면과 뒷면 모두 위치·크기를 개별 조절합니다. 확대 보기의 뒷면은 저장한 배율과 위치를 적용하며, 스와이프 중에도 구도가 유지됩니다. 앞면 확대는 원본 전체 보기입니다.

메뉴 없는 확대 감상, 방향을 따라 움직이는 스와이프, 화면 클릭·Esc로 닫기와 베이지색 선택 버튼을 유지합니다. 1.01 이하에서 업데이트 시 INSTALL.md의 저장 모델 병합 안내를 따릅니다.
