# Watch Collection Ver. 1.05

설치 페이지: https://watch-collection-v1.jamm2nd.chatgpt.site/

사진 확대 보기에서 앞·뒷면을 좌우로 스와이프할 수 있습니다. 각 면의 원본 사진을 미리 준비하고 별도로 유지하여, 전환 중 앞면이 잘려 보이는 현상을 수정했습니다. 스와이프 이후 첫 터치로 바로 닫을 수 있습니다.

뒷면도 앞면과 동일하게 위치·크기를 조절할 수 있으며, 저장한 뒷면 구도가 확대 보기와 스와이프에 적용됩니다. 앞면 확대는 원본 전체를 표시합니다.

설치 안내는 INSTALL.md를 읽습니다. manifest.json과 restore.py를 사용하여 모든 소스 파일의 크기와 SHA-256을 검증합니다. Sites 제작·배포 도구와 소스 다운로드가 가능한 작업 환경이 필요합니다. 링크는 해당 도구를 활성화하지 않습니다.

기존 컬렉션 업데이트는 데이터·사진·개인 설정·사이트 주소·공유 권한을 유지합니다. 배포 원본에는 기본 샘플 5개만 포함되며 개인 컬렉션 데이터는 포함하지 않습니다.
